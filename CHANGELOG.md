## [1.0.0] - 2026-09-18

### Added
- **Prop Scatter** editor window — paint prefabs on any collider from a `PropPalette`.
- **Decal Projector** editor window — paint URP `DecalProjector` components from a `DecalPalette`.
- **Palette Creator** menu items — create new `PropPalette` and `DecalPalette` assets from `Tools/FD Painters`.
- Optional random yaw and random scale for both tools.
- Click-and-drag painting.
- Keypad 0–9 palette switching.
- Adjustable Y offset for the Decal Projector.
